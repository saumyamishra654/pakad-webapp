# Samvad - Raga Chord Tool

This is a React-based web application for exploring Indian Classical Music (Ragas) and Western Harmony.

## Project Structure

- `src/components`: Reusable UI components
- `src/pages`: Main application pages (ChordTool, QueryTool, Insights)
- `src/utils`: Helper functions and logic
- `public`: Static assets

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Technologies

- React
- Vite
- Tailwind CSS
- React Router DOM
